# Controls and commands

All keys of the mod can be changed in **Options → Controls → Key Binds** (category *JTechStorage*).

## Keys

| Key | Action | Page |
|---|---|---|
| **K** | open the companion menu | [Companions](07-companions.md#companion-menu) |
| **B** | companion: special attack | [Companions](07-companions.md#special-attacks) |
| **G** | companion: follow / stay (up to 48 blocks away) | [Companions](07-companions.md#following-staying-and-calling) |
| **H** | Amethyst Shroom: heal now | [Companions](07-companions.md#amethyst-shroom) |
| **Shift + H** | Amethyst Shroom: automatic healing ↔ on key | [Companions](07-companions.md#amethyst-shroom) |
| **R** | Cheldrogan (riding): crystal breath | [Cheldrogan](05-cheldrogan.md#riding) |
| **V** | Cheldrogan (riding): crystal shard rain | [Cheldrogan](05-cheldrogan.md#riding) |
| **Left click** | Cheldrogan (riding): tail sweep | [Cheldrogan](05-cheldrogan.md#riding) |
| **Inventory key** while riding | chest (Storage Griffin) or menu (Amethyst Phoenix) | [Helpers](04-helpers.md) |
| **Jump** while riding | take off / rise (Cheldrogan, raven); short flight (mantis); depart early (Amethyst Phoenix, front seat) | |
| **Shift** over an item | show its controls in the tooltip | |

## Storage Key

| Action | Effect |
|---|---|
| Sneak + right-click a Storage Terminal | bind the key to it |
| Sneak + right-click a chest, barrel, shulker box or Amethyst Chest | link / unlink it |
| Click a helper, Team or Trade Terminal, Phoenix Nest, Night Raven | link it to the network |
| Look at a chest with the key in hand | show its sorting category (with an Amethyst Sprite) |
| Right-click in the air (with *Recall*) | teleport back to your terminal, once per day |

## Storage Terminal

Items are taken and stored like in a chest. The search field is active when the terminal opens – click into the item
grid first to use the number keys and Q.

| Action | Effect |
|---|---|
| Left click | take a stack |
| Right click | take half a stack |
| Shift + click | move a stack into your inventory |
| Left click with an item | store it (on a different item: store it and pick that one up) |
| Right click with an item | store one |
| 1–9 / swap-offhand key over an item | put a stack into that hotbar slot / your offhand (what was there is stored) |
| 1–9 over an empty field | store that hotbar slot |
| Q / Ctrl + Q over an item | drop one / a stack |
| Middle click (creative) | pick up a full stack without taking it |
| Shift + click in your inventory | store it |
| Right-click the search field | clear the search |
| Click the active category tab again / right-click a tab | show all items |

## Helpers

| Action | Effect |
|---|---|
| Right-click | main action (status, menu or mount) |
| Sneak + right-click twice | pack up into an item |
| Dye / hat item / shears | recolor / put on a hat / reset |

## Companions

| Action | Effect |
|---|---|
| Right-click | follow / stay (mantis in your base: stand guard); at stage 3 mount (mantis, raven) |
| G / companion menu | the same for a companion on your shoulder, which can't be clicked |
| Companion menu → *Explore* | send the Night Raven on an exploration trip |
| Companion menu → *Look* | coloring, body parts, glow color and equipment ([Customization](07-companions.md#customization)) |
| Shift + right-click | companion menu (mantis, shroom) or bag (raven) |
| Right-click with a Resonance Treat | double experience, speed, healing |
| Right-click the raven with a bound Storage Key | link it to the terminal / send it off right away |
| Right-click the Geode Keeper | companion offer, or trades once you have a companion |
| Shift + right-click the Geode Keeper | trades |

## Commands

| Command | Permission | Effect |
|---|---|---|
| `/jtechstorage companion call` | everyone | bring your companion to you, even from another dimension |
| `/jtechstorage companion release confirm` | everyone | release your companion for good |
| `/jtechstorage companion accept` / `decline` | everyone | answer a Geode Keeper's offer |
| `/jtechstorage companion keeper` | operator | spawn a Geode Keeper in front of you |
| `/jtechstorage companion xp <amount>` | operator | give your companion experience |
| `/jtechstorage storm start` | operator | start a Resonance Storm at the nearest terminal (within 64 blocks) |
| `/jtechstorage storm stop` | operator | end the storms near you |
