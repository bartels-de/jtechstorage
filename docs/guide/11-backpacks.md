| Iron | 18 | leather backpack + iron block |
| Gold | 27 | iron backpack + gold block |
| Diamond | 36 | gold backpack + diamond block |
| Netherite | 54 | smithing table: netherite upgrade template + diamond backpack + netherite ingot – fireproof |

Upgrading **keeps the contents**.

## Using a backpack

| Action | Effect |
|---|---|
| Right-click | open it |
| Put it in the chest armor slot | wear it – it is visible on your back |
| Crafting grid: backpack + dye | dye it |
| Sneak + right-click on the ground | place it as a block (hoppers can fill and empty it) |
| Right-click a placed backpack | open it |

- Items you pick up go **into a backpack that already contains them**.
- The [Amethyst Sprite](04-helpers.md#amethyst-sprite) empties placed backpacks near the terminal into your network.
